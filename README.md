A visually interactive website built with React, using animations and effects powered by GSAP, Simple Parallax, and Atropos.js. **Note:** Currently optimized for desktop only.

## Demo

Site is Live at https://mahdih80.github.io/portfolio/

## Features

- Smooth animations with **GSAP**
- Parallax scrolling effect with **Simple Parallax**
- Layered 3D effects using **Atropos.js**
- Desktop view optimized

## Technologies Used

- **React** - JavaScript library for building the UI
- **GSAP** - For smooth, customizable animations
- **Simple Parallax** - Parallax scrolling effects
- **Atropos.js** - 3D, layered animations

## Limitations

- **Mobile Compatibility**: Currently, the site is not optimized for mobile devices and will not display on phones.
